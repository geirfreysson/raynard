# Raynard v0.6.0

A small release: the chats sidebar can now be searched.

## Search your chats

The Chats sidebar has a search field that filters saved chats by title as you
type. Matching is case-insensitive and happens locally — nothing is sent
anywhere, and your stored history is not touched. A query that matches nothing
says so, rather than leaving you with an unexplained empty list.

## First automatic update

If you are on 0.5.0, this is the first release Raynard can install for you.
Open Settings from the gear at the foot of the sidebar, or run `/settings`, and
Raynard will offer 0.6.0 — download and restart from there.

Anyone still on 0.4.0 or earlier has no updater in their build and needs to
install this one by hand; after that, updates arrive in the app.
